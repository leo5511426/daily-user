# 行動會員通知設定第一階段（隔離測試）

目前正式分支維持回復後的 r6 系統，這個測試分支不可合併或發布為正式版。

本階段只加入會員通知偏好、LINE／Facebook Messenger／Instagram 聯絡資料，以及管理員確認／撤銷確認。沒有建立待發送清單、批次登記，也不會發送社交通知。既有通知模式及業務邏輯維持原樣。

## 測試環境

- 獨立 Apps Script 專案，不能使用正式專案的新增部署，也不能從試算表副本開到正式專案後直接覆蓋程式。
- `NotificationSettings.gs` 是增量模組；配合私下提供的 `CoreForIsolatedTest.gs.txt`（基於 r6）才可進行完整測試。
- 測試核心的所有試算表存取都固定到已核對的隔離測試資料；有環境標記及指令碼屬性雙重核對。
- 只開放本階段所需的登入、工作階段、資料讀取、客服及通知設定操作。附件、外部物流及管理員財務寫入未開放。
- Preview 必須設定 `TEST_GAS_URL` 及 `TEST_SPREADSHEET_ID`，且前者必須與 `GAS_URL` 不同。每次業務請求前先核對後端身分，不符合就停止，不會傳出登入憑證或業務操作。
- 前端移除直接連到正式 GAS 的 fallback。瀏覽器不會收到代理秘密。
- 第一階段通知 API 在 Production 環境保持關閉。

## 設定儲存

`MemberNotificationSettingsV1` 採用完整快照逐列追加，設定及修改人／時間一起保存。版本衝突會要求重新載入；同一請求重試不會再次追加。更換管道或聯絡資料後重新變成待確認。會員只能讀寫自己設定，管理員確認必須使用最新版本。

## 驗證狀態

已完成本機模擬：沿用 r6 實際密碼驗證／雜湊升級與工作階段登入、通知設定儲存與讀取、聯絡確認、改聯絡資料、重試、版本衝突、不同會員隔離、登出失效，以及錯誤試算表／後端阻擋。

尚未完成：真實 GAS 部署、真實登入→儲存→重新登入讀取、後台確認→會員查看、正式功能的測試環境回歸。上述項目完成前不可聲稱已上線或完整可用。
